# 04 · Evidence Contract

Freeze schema v1 **conventions** in milestone one — asset identifiers, units, timestamps, missingness, lineage, policy references, output status — then evolve fields. Unknown major versions are rejected. **A model cannot silently consume a new feature under the old hash.**

## Numeric and time conventions

- Token amounts: integer base units, decimal strings in JSON
- Token identity: chain ID + contract address. **Symbols are not identifiers**
- Price: integer mantissa + declared scale + quote asset
- Rates: integer basis points annually; probabilities at a declared fixed scale
- Checked integer or fixed-decimal arithmetic. **No floating-point path produces an amount used in authorization**
- Timestamps distinguish observation, retrieval, assessment, and virtual scenario time
- Asset values round down; permitted debt rounds down; obligations round up
- Reference vectors cover every cross-language conversion
- The engine receives assessment time explicitly; the contract checks chain time independently

## Evidence envelope

```text
Evidence<T>
  value: T | absent
  state: Present | Missing | Stale | Conflicting | Unsupported
  source
  origin: Observed | Synthetic | PolicyAssumption
  observed_at, retrieved_at
  chain_id?, block_number?, block_hash?, transaction_hash?
  scope, coverage: Complete | Partial | Unknown
  evidence_id, content_hash, parent_evidence_ids[]
  scenario_id?, method_version?
```

**Live retrieval is a property of acquisition, not a guarantee of truth.** A provider response can be current *and* incomplete. A fill can be onchain *and* generated by two scenario bots. Preserve both facts. Derived features retain parent references and derivation version.

### Provenance as a feature

```text
37 repayments, exposure-weighted   +142   [live: Credence]
Low historical drawdown            +104   [scenario]
ETH concentration                   -41   [live: Perpl]
```

A judge reads rigor, not hand-waving. Full narrative scope **and** complete honesty.

## RiskAssessment — minimum

```text
assessment_id, schema_version
model_id, model_hash, policy_hash
input_hash, evidence_root
binding, request_id, intent_hash, assessment_time
decision: Approved | Denied | Unavailable
authorization_class: ScenarioOnly | ObservedShadow | PrototypeEligible
proposed_terms?              # principal, apr_bps, term_seconds, max_ltv,
                             #   required_equity, available_credit
proposed_action_bounds?
outstanding_exposure, available_credit, marked_value,
  stressed_values[], binding_constraints[]
trust_summary, portfolio_risk_summary
forecast_quality_summary, evidence_quality_summary
reasons[]                    # stable codes + parameters + evidence refs
assumed_pd?, assumed_lgd?, scenario_expected_loss?
confidence                   # evidence completeness, NOT model certainty
policy_epoch, sequence, valid_after, valid_until
```

Missing evidence produces `Unavailable` with an informative explanation and **no executable terms**. It must never produce an apparently approved zero-risk loan. An observed/shadow approval remains non-executable by authorization class.

### Mapping from the original output spec

Several entries are **narrower claims**, not renamings. Do not read this as equivalence.

| Original | Here | Change |
|---|---|---|
| `credit_limit` | `facility_limit` | — |
| *(request)* | `requested_principal` | new, explicit |
| *(grant)* | `approved_principal` | new, explicit |
| `available_credit` | `available_credit` | **narrower** — headroom, not necessarily drawable |
| `recommended_apr` | `proposed_terms.apr_bps` | — |
| `max_ltv` | `proposed_terms.max_ltv` | **defined here**, not inherited |
| `required_collateral` | `proposed_terms.required_equity` | **narrower** — equity only |
| `probability_of_default` | `assumed_pd` | **narrower** — assumption, not estimate |
| `expected_loss` | `scenario_expected_loss` | **narrower** — scenario-conditional |
| `trust_score` / `risk_score` | `trust_summary` / `portfolio_risk_summary` + derived score | restructured |
| `risk_reasons` | `reasons[]` with stable codes | strengthened |
| `confidence` | `confidence` | **redefined** — evidence completeness |
| `model_version` | `model_id` + `model_hash` | — |
| `features_hash` | `input_hash` + `evidence_root` | — |

**`required_equity` is not total collateral.** The account holds contributed equity *and* assets bought with borrowed funds; both secure the debt, only the first is the agent's contribution.

**`max_ltv` is `debt_including_accrued_interest / net_recoverable_value`** — not the conventional `principal / gross_market_value`. Publish the formula beside the number.

## Evidence policy

| Problem | Behavior |
|---|---|
| Missing balances, debt, binding, or valuation | No new authorization |
| Stale required market observation | No risk-increasing action; repayment stays open |
| Conflicting prices beyond tolerance | Unavailable pending resolution |
| No repayment history | New account, base cap, no history uplift |
| Missing optional enrichment | Omit feature, explain absence, **no clean-history benefit** |
| Forecast outcome unmeasurable | Unresolved; no success credit |
| Synthetic required evidence | Scenario-only authorization domain |
| Bot-generated note prices | Informational panel only |

**Missing debt is unknown debt, not zero debt. Missing liquidation records are not a clean history.**

## Determinism and replay

```text
assess(canonical_input, pinned_model, pinned_policy) -> canonical_assessment
```

No I/O, clock access, entropy, or hash-map iteration dependence. Randomized generation lives outside the engine.

Define canonical encoding once: UTF-8, deterministic key ordering, fixed decimal strings, no non-finite values, deterministic ordering of semantically unordered collections. Reject duplicate evidence IDs. Preserve order where it represents a real sequence. **Shared reference vectors prove Go and Rust produce identical snapshot hashes.**

Persist exact input and output **bytes**, not a row that could later be reconstructed differently. Hash model and policy independently.

**Replacing a simulated observation with an observed one changes lineage and therefore the snapshot hash even when the numeric value matches.** Do not promise byte-identical assessments across evidence-source changes.

**Reproducing an output establishes consistency, not statistical accuracy.**

```text
credence scenario run     --id performer --seed 184
credence risk assess      --input fixtures/performer/input.json
credence risk replay      --assessment <id>
credence evidence inspect --assessment <id>
credence scenario compare --run <a> --run <b>
```

## Persistence

| Table | Purpose |
|---|---|
| `agents`, `bindings` | Identities, operator/account relationships, config versions |
| `observations`, `evidence_edges` | Immutable versions, derived-feature lineage |
| `snapshots`, `assessments` | Exact canonical input/output blobs and hashes |
| `models`, `policies` | Pinned artifacts, parameters, compatibility |
| `intents`, `forecasts`, `outcomes` | Commitments, append-only resolutions |
| `chain_events`, `chain_cursors` | Ordered events, indexing position |
| `transactions`, `jobs` | Submission status, idempotency keys, retries |
| `scenario_runs`, `scenario_events` | Runs, seeds, generator version, ordered events |

WAL, foreign keys, migrations, busy timeout. **One writer.** Index by chain ID, transaction hash, log index. Detect reorgs and rebuild projections — **preserve the original evidence trail with an invalidation marker rather than deleting the fact that a decision was made.**

Retries reconcile receipts and onchain state before resubmitting. Request IDs and contract nonces give exactly-once economic effects; network delivery is not exactly once.

Read critical account state at a **common block reference** where possible; record any source that cannot and apply a declared max age and skew policy. **Never combine a current debt amount with an older balance without detecting the mismatch.**

Retain enough normalized and source material to explain an observation later. **A hash without retrievable evidence is insufficient for replay.**
